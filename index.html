Shared craft rules

Different faces, same standards.

The visual languages differ on purpose. The quality floor does not move.

Motion that degrades

Every animation is gated behind reduced-motion preferences, and content is fully visible without JavaScript.

Contrast measured

Body text was checked against each canvas; the palette panel on every page shows the ratio it actually achieves.

Keyboard first

Visible focus rings, real buttons, ARIA pressed states and labelled canvases throughout.

Honest demos

Nothing connects to a server, camera or patient record. Each page states that boundary next to its prototype.

!

Scope. These are design studies for healthcare software, built to be looked at and clicked — not clinical tools. They contain no patient data, no diagnosis, and no medical device logic.

How to use this pack

One folder, twelve arguments.

Open index.html (this page), then any concept. Each file is standalone: fonts load from Google Fonts, everything else — SVG, canvas, styles, scripts — travels inside the file. Send a single concept to a stakeholder without sending the rest.
